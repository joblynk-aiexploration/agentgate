# Ecommerce Customer Journey Report

## Tested Journey

1. Customer opens the Northstar store.
2. Customer logs in.
3. Customer adds product to cart.
4. Customer checks out.
5. Customer opens account and order detail pages.
6. Customer views tracking.
7. Admin updates fulfillment.
8. Customer tracking reflects the new state.

## Result

Passed in automated browser/integration coverage after resetting the commerce data.

## Notes

The flow is local-demo only. It does not process real payments, send real shipment updates, or call real external commerce systems.
